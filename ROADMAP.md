# Roadmap — cero-X App

## v0.1 — Núcleo Base (Semana 1-2)
- [ ] Arquitectura modular con event bus
- [ ] Sistema de configuración YAML
- [ ] Registro de módulos y ciclo de vida
- [ ] CLI de entrada y gestión de módulos
- [ ] Suite de pruebas unitarias básica

## v0.2 — Módulo Lector (Semana 3-4)
- [ ] Integración con arquitectura Mihon/Komikku
- [ ] Sistema de extensiones para fuentes de manga
- [ ] Gestión de biblioteca local
- [ ] Lectura offline-first
- [ ] Sincronización de progreso

## v0.3 — Módulo Audio (Semana 5-6)
- [ ] Índice de música integrado (Wotaku-based)
- [ ] Reproductor de audio local
- [ ] Descarga y caché de audio
- [ ] Listas de reproducción

## v0.4 — Módulo Video (Semana 7-8)
- [ ] Reproductor de video con codecs abiertos
- [ ] Gestión de biblioteca de video
- [ ] Subtítulos y metadatos
- [ ] Streaming local

## v0.5 — Módulo IA y Entrenamiento (Semana 9-10)
- [ ] ONNX Runtime integrado para inferencia on-device
- [ ] Fine-tuning de modelos locales
- [ ] Generación de contenido con IA
- [ ] Optimización para CPU y NNAPI

## v0.6 — Ingeniería Inversa (Semana 11-12)
- [ ] Herramientas de análisis de binarios
- [ ] Clonación de ecosistemas de terceros
- [ ] Integración con DeepSeek Harness para evaluación
- [ ] Análisis de protocolos y APIs

## v0.7 — Gestor de Entornos (Semana 13-14)
- [ ] Soporte para Debian estable/testing
- [ ] Contenedores y máquinas virtuales ligeras
- [ ] Entornos de desarrollo aislados
- [ ] Gestión de dependencias por entorno

## v1.0 — Release Estable (Semana 15-16)
- [ ] Integración completa de todos los módulos
- [ ] Pruebas de estrés y rendimiento
- [ ] Documentación de usuario final
- [ ] Release público bajo licencia Apache-2.0

---

*Inspirado en el núcleo de Linux: abierto, modular, comunitario.*
